# Blaugrana Nova — نسخة مستقلة جديدة

تطبيق عربي من اليمين إلى اليسار لمتابعة برشلونة، مبني بواجهة JavaScript/CSS مستقلة داخل Capacitor، ويُبنى كـ Android APK عبر GitHub Actions.

## ما يتضمنه المشروع

- واجهة متجاوبة داكنة بأسلوب زجاجي، بألوان مستوحاة من برشلونة مع لمسات ذهبية، وشريط تنقل سفلي.
- صفحة رئيسية تعرض الموعد القادم والنتائج الحديثة والأرقام المحسوبة من البيانات المستلمة فقط.
- مركز مباريات بفلاتر للقادمة والمباشرة والمنتهية، مع تقرير المباراة إذا وفّر المصدر تفاصيله.
- جداول ترتيب تُقرأ من المصدر، ودليل أندية يفتح قوائم اللاعبين، وصور فعلية عند توافر روابطها من المزوّد.
- أخبار من المصدر الخارجي، ومحاولة ترجمة عناوينها وملخصاتها إلى العربية عند الطلب أو عند فتح الأخبار.
- حفظ الأخبار، وتوقعات محلية للمباريات القادمة، وأداة اختيار تشكيلة محلية، وتحليل يُحسب من النتائج النهائية الفعلية، واختبار معلومات كروية، ومركز تنبيهات داخل التطبيق، وإعدادات للمظهر والحركة.
- تخزين مؤقت محدود للبيانات، ومهلات للطلبات، واستخدام البيانات المحفوظة عند تعذّر الاتصال.
- اختبارات لوحدات تطبيع البيانات، وفحص صياغة JavaScript، وسير عمل GitHub لبناء APK ورفعه كـ Artifact.

## النزاهة ومصادر البيانات

- تستخدم المباريات، والجداول، وقوائم اللاعبين، والأخبار واجهات ESPN Soccer العامة. لا يتطلب هذا التنفيذ مفتاح API داخل التطبيق.
- روابط صور الأندية واللاعبين تُؤخذ من استجابات المزوّد. لا توجد صور لاعبين ثابتة أو بيانات مباريات تجريبية مكتوبة داخل الواجهة. عند غياب الصورة يظهر اختصار الاسم.
- تُعرض النتائج والأرقام كما يرجعها المصدر. القيم الناقصة تبقى `—` بدلاً من تعويضها برقم مختلق.
- الترجمة آلية عبر خدمة ترجمة عامة دون ضمان توافرها أو دقتها أو السماح بكل الطلبات. عند تعذّر الترجمة يُعرض النص الأصلي.
- واجهات البيانات العامة قد تتغير أو تتوقف، وقد لا تغطي كل المسابقات أو كل اللاعبين. يجب مراجعة شروط المزوّد قبل الاستخدام التجاري.
- التوقعات والتشكيلة والأخبار المحفوظة والإعدادات محلية لهذا الجهاز، ولا تُرسل إلى خادم.

## فحص المشروع محلياً

يتطلب Node.js 22 أو أحدث، ويفضّل استخدام Java 21 لبناء Android.

```bash
npm install
npm run check
npm test
```

## بناء APK على GitHub

1. أنشئ **مستودعاً جديداً فارغاً** على GitHub، مثلاً `Blaugrana-Nova-Complete`، ولا تخلط الملفات مع مشروعك القديم.
2. ارفع محتويات مجلد المشروع إلى جذر المستودع على فرع `main`، بحيث يظهر `package.json` و`www/` و`.github/` في الجذر مباشرة.
3. افتح **Actions** وشغّل `Build Blaugrana Nova APK` عبر `Run workflow`، أو ادفع commit إلى `main`.
4. افتح نتيجة التشغيل الناجح ونزّل الملف من قسم Artifacts باسم `Blaugrana-Nova-debug-apk`.

ملف APK التجريبي الناتج من GitHub Actions قابل للتثبيت للاختبار، لكنه ليس إصداراً موقّعاً للنشر في متجر Google Play. يحتاج النشر العام إلى إعداد توقيع إصدار ومراجعة سياسات المتجر.

## بناء محلياً بعد تثبيت Android SDK

```bash
npm install
npm run check
npm test
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

مسار APK المعتاد: `android/app/build/outputs/apk/debug/app-debug.apk`.

## بنية الملفات

- `www/index.html`: نقطة الدخول العربية RTL.
- `www/styles.css`: المظهر المتجاوب.
- `www/src/app.js`: الشاشات والتفاعلات.
- `www/src/api.js`: الاتصال بالمصادر والتخزين المؤقت والترجمة.
- `www/src/normalizers.js`: توحيد أشكال الاستجابات الخارجية.
- `www/src/store.js`: التخزين المحلي.
- `www/src/config.js`: عناوين الخدمات وإعدادات الطلبات.
- `tests/normalizers.test.js`: اختبارات تطبيع البيانات.
- `.github/workflows/build-apk.yml`: الفحص وبناء Android APK.

## ملاحظات مهمة

هذه نسخة مشروع جديدة مستقلة وليست تعديلاً على ملفات Termux الحالية. لا أستطيع ضمان أن خدمة خارجية أو كل مباراة ستظل متاحة دائماً؛ لذلك يجب مراجعة نتيجة Actions قبل تثبيت APK. لم يتضمن ZIP أي مفاتيح سرية أو بيانات حسابات.
